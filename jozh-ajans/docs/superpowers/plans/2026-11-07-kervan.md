# Kervan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kervan dizisinin ilk 50 bölümünü (hikâye kitabı + bölüm verileri) yazıp, telefonda açılan tek HTML üretim sayfası olarak yayınlamak.

**Architecture:** Hikâye ve bölümler Python veri dosyalarında durur (tek doğru kaynak). `build.py` taslakları doldurur, denetimleri çalıştırır ve `sablon.html` + Dedemin Defteri'nin `kasa-motor.js` dosyasını tek bir `yayin/kervan.html` içine gömer. Sayfa claude.ai Artifact olarak yayınlanır; düzeltmeler aynı dosyadan aynı bağlantıya yeniden yayınlanır.

**Tech Stack:** Python 3.13 (yalnızca standart kütüphane, `unittest`), düz HTML/CSS/JS, Playwright (yalnızca duman testi için, önceden kurulu).

**Spec:** `jozh-ajans/docs/superpowers/specs/2026-11-05-kervan-design.md`

## Global Constraints

- Kök klasör: `jozh-ajans/kervan/`. Testler: `jozh-ajans/kervan/tests/`, çalıştırma: `cd jozh-ajans/kervan && python3 -m unittest -v`.
- 50 bölüm; her bölüm tam 15 senaryo × 8 saniye; dikey 9:16.
- Kasa: B01 ilk rakamı **200.000 ₺**; zincir kesintisiz; B50 son rakamı 2.700.000–3.300.000 ₺ arası; tüm kasa rakamları > 0.
- Karakterler: Kerem (20, gezi), Defne (19, dükkân/kasa), Kaan (18, kafe). Sabit İngilizce tarifler tek yerde (`karakterler.py`), promptlara harfi harfine girer.
- Kapak 1 ve Kapak 2 taslak metinleri spec 4.1/4.2'den **birebir**; yalnızca köşeli parantezler doldurulur.
- Promptlar İngilizce; bölüm adı, "PEK YAKINDA" ve replikler Türkçe. Replik ≤ 8 kelime.
- Kötü adam yok; aksilikler doğal sebepli.
- Kasa motoru kopyalanmaz: build sırasında `icerik/dedemin-defteri/kasa/kasa-motor.js` okunup gömülür.
- Sayfa sırası (bölüm): Kapak 1 → Kapak 2 → Açıklama → Sabit kasa → Senaryo 1–15 (değişen senaryoda altında kasa promptu) → Önceki/Sonraki. Sekmeler: Bölümler, Karakterler, Rota, Kasa Aracı, Profil.
- Profil: kullanıcı adı `kervan.dizi`, ad `Kervan`, biyografi spec'teki 4 satır (IG ≤150, TikTok ilk 2 satır ≤80).
- İstatistik ve otomatik paylaşım yok.

## Review Focus

1. **Parti sınırında kasa kopması** (B10→B11 gibi ayrı dosyalar): zincir dosyalar arası da kontrol edilmeli → Task 3 testi `test_kasa_zinciri_dosyalar_arasi`.
2. **iPhone'da Kopyala** (Clipboard API reddi): yedek yöntem (`textarea` + `execCommand`) çalışmalı ve "Kopyalandı" görünmeli → Task 4 Playwright adımı izinsiz bağlamda dener.
3. **localStorage kapalı** (gizli sekme): sayfa yine açılmalı, sadece işaretler hatırlanmamalı → Task 4 testi `localStorage` erişimi hata fırlatırken sayfayı açar.
4. **Türkçe karakterler** (İ, ı, ş, ğ, ₺) prompt ve açıklamalarda bozulmamalı → Task 4 testi çıktıda `"KERVAN"`, `"İ"` ve `"₺"` içeren örnek metni byte düzeyinde doğrular.
5. **Dar ekranda taşma** (uzun prompt satırları): 375 px genişlikte yatay kaydırma olmamalı → Task 4 Playwright adımı `scrollWidth <= 375` doğrular.

### Task 1: Hikâye kitabı (karakterler, defter, 50 bölüm rotası ve kasa planı)

**Files:**
- Create: `jozh-ajans/kervan/hikaye.md` — anlatı: defterin sahibi (adı, yılı, kim olduğu), yarım kalmış hikâyesi, 50. bölümde açılacak sır, 51–100 için yön; her bölüm için tek satır özet.
- Create: `jozh-ajans/kervan/karakterler.py`
- Create: `jozh-ajans/kervan/rota.py`
- Test: `jozh-ajans/kervan/tests/test_hikaye.py`

**Interfaces:**
- Produces: `karakterler.K: dict[str, str]` — anahtarlar `"kerem"`, `"defne"`, `"kaan"`; değer = sabit İngilizce görünüm tarifi (yüz, saç, ten, boy, kıyafet, aksesuar; 60–110 kelime). `karakterler.referans_prompt(ad: str) -> str` — karakter referans görseli promptu.
- Produces: `rota.ROTA: list[dict]` — 50 öğe, anahtarlar: `no:int, sehir:str, baslik:str, alinan:str, satilan:str, kasa_bas:int, kasa_son:int, aksilik:str, ipucu:str, son:str` (cliffhanger cümlesi).

- [ ] **Step 1: Write the failing test** — `test_hikaye.py`:
  - `test_elli_bolum`: `len(ROTA) == 50` ve `[b["no"] for b in ROTA] == list(range(1, 51))`.
  - `test_kasa_baslangic`: `ROTA[0]["kasa_bas"] == 200_000`.
  - `test_kasa_zinciri`: her `i>0` için `ROTA[i]["kasa_bas"] == ROTA[i-1]["kasa_son"]`.
  - `test_kasa_hedef`: `2_700_000 <= ROTA[-1]["kasa_son"] <= 3_300_000`.
  - `test_kayiplar_var`: `kasa_son < kasa_bas` olan bölüm sayısı `>= 6`.
  - `test_ilk_sehir`: `ROTA[0]["sehir"] == "İstanbul"`.
  - `test_karakterler`: `set(K) == {"kerem","defne","kaan"}`; her tarif 60–110 kelime; `"kaan"` tarifinde `"18"`, `"defne"`de `"19"`, `"kerem"`de `"20"` geçer.
  - `test_bos_alan_yok`: her bölümde tüm str alanlar boş değil.
- [ ] **Step 2: Run** `cd jozh-ajans/kervan && python3 -m unittest tests.test_hikaye -v` → FAIL (`ModuleNotFoundError: rota`).
- [ ] **Step 3: Write** `karakterler.py`, `rota.py`, `hikaye.md`. Rota: İstanbul'dan başlar, defterin izinden mantıklı bir hat çizer (zikzak yok), her şehirde gerçek yöresel ürün. Bölüm 50: defterin büyük sırrı açılır.

- [ ] **Step 5: Kullanıcı onayı** — hikâye kitabının özetini (defterin hikâyesi, karakterler, 50 satırlık rota/kasa tablosu) sohbette sun; onay gelmeden Task 3'e geçme (Task 2 bağımsız, beklerken yapılabilir).

### Task 2: Prompt şablonları

**Files:**
- Create: `jozh-ajans/kervan/sablonlar.py`
- Test: `jozh-ajans/kervan/tests/test_sablonlar.py`

**Interfaces:**
- Produces:

  - `kapak2(...)` aynı imza.
  - `senaryo(no: int, rol: str, kimler: list[str], mekan: str, aksiyon: tuple[str, str, str], kamera: str, replik: tuple[str, str] | None, ses: str, duygu: str) -> str` — `rol` ∈ `{"HOOK","ARRIVAL","TRADE","CRISIS","SECRET","CLIFFHANGER"}`; `kimler` karakter anahtarları (`K`'den tarif alınır).

- [ ] **Step 1: Write the failing test** — `test_sablonlar.py`:
  - `test_kapak1_birebir`: örnek doldurmada çıktı, spec 4.1 metninin köşeli parantezler dışındaki her satırını içerir (spec dosyasından kod bloğu okunup `[...]` içeren satırlar atlanarak karşılaştırılır).
  - `test_kapak2_pek_yakinda`: çıktıda `"PEK YAKINDA"` 3 kez (başlık, metin, izin listesi); Kapak 1'in kapanış bloğu (`'The ONLY permitted text elements are:\n“BÖLÜM 5”\n“FINDIK”'` + satır sonu ile biten hali) yok.

  - `test_replik_yok`: `replik=None` → `"DIALOGUE: No dialogue."` içerir.
  - `test_replik_siniri`: 9 kelimelik replik → `ValueError`.
  - `test_karakter_birebir`: `senaryo(..., kimler=["defne"], ...)` çıktısı `K["defne"]` metnini aynen içerir.
- [ ] **Step 2: Run** `python3 -m unittest tests.test_sablonlar -v` → FAIL.
- [ ] **Step 3: Implement** — spec metinlerini sabit string olarak koy, `str.replace` ile doldur.
